## Summary

Pixel Place now includes an age-based mode picker that helps players choose the best play experience for them.

- **Kids**: a 3D-inspired, friendly mode for players aged 0–10.
- **Now**: a minimalist and fun mode for players aged 11–20.
- **Unlimited**: a bold, older-player mode for ages 21+.

The flow shows a “Checking eligibility” wait state for 2–5 seconds after age entry, then unlocks the choices you can use.

## What’s new in 3.02

- Added the **Pixel Place Modes** eligibility experience after login.
- Players enter their age and receive a random 2–5 second eligibility check.
- Eligible modes are highlighted and selectable based on age rules:
  - Ages 0–10: Kids only
  - Ages 11–14: Kids + Now
  - Ages 15–20: Now only
  - Ages 21+: Now + Unlimited
- Each mode includes curated sample games and a distinct visual style:
  - **Kids**: 3D-ish drop-shadow playful card
  - **Now**: minimalist, clean, fun design
  - **Unlimited**: mature, bold, grown-up presentation
- The selected mode is saved per user in browser storage so the experience stays consistent after login.
