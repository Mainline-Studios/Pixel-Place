## 📝 First Time Setup

1. Run `npm install`
2. Run `npm run dev`
3. Open `http://localhost:3000`
4. Create an account or login with admin credentials
5. Start creating!

## 🎨 Features to Test

1. **Avatar Shop**: Go to Avatar Shop tab → See 3D avatars that rotate with mouse
2. **Create Game**: Go to Studio → Use AI Generator or Code Editor
3. **Publish Game**: Add thumbnail, enable multiplayer, publish
4. **Buy Server**: Go to Servers tab → Purchase a server for your game
5. **Play Online**: Go to Discover → Click "Play Online" on multiplayer games
6. **Buy Coins**: Go to Pixel Coins tab → Purchase with Stripe (test mode)

## ⚠️ Important Notes

- **Stripe**: Optional - app works without it (payments just won't process)
- **Socket.io Server**: Optional - games work offline without it
- **Port 3000 Busy?**: Use `npm run dev -- -p 3001` then open `http://localhost:3001`
