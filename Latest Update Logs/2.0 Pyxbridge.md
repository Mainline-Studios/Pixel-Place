## Summary

**Pyxbridge** marks the integration of **Pyx** into Pixel Place: AI-assisted moderation, filtering, and coding bridges between player content and safer display.

## Highlights

- **Pyx APIs** — `/api/pyx/check`, `/api/pyx/filter`, analyze/complete/feedback routes; optional `PYX_SERVICE_URL` with Claude fallback.
- **Pyx client** — `pyx-client.js` loaded from the root layout; `LocalizeText` and display paths filter user-generated strings.
- **AI Coder** — Pyx-powered coding assistance for creators (donor/full access tiers).
- **Eco Hero & trainers** — Pyx-adjacent AI chat flows for in-game experiences.
- **Game generation** — Server routes tying generative tooling into Studio workflows.

This era connected “raw” user text and studio output to automated checks before it reached the UI or published games.
