## Summary

**Pyxbridge** is the **mobile and touch** era: Pixel Place becomes usable on phones and tablets without treating them as shrunken desktop tabs. Layout, controls, and game input adapt when the device is touch-first.

## Highlights

- **Mobile beta layout** — `MobileBetaProvider` detects phones, tablets, and iPadOS (coarse pointer, UA, viewport) and switches to a simplified experience; **MOBILE BETA** badge in the top bar.
- **Settings override** — “Use full desktop layout on this device” (`pixelplace_force_desktop`) for power users on small screens; `?desktop=1` query bypass.
- **Games on mobile** — HistoriMac hidden on mobile beta (desktop-oriented); catalog messaging explains the simplified layout.
- **Touch controls** — Showdown gets an on-screen D-pad; built-in games (e.g. Floor Is Lava, Obstacle Course) use touch/pinch handlers; shared game-engine touch input.
- **Installable / mobile web** — `mobile-web-app-capable` and Apple web-app meta tags; PWA deploy docs for home-screen install.
- **Responsive shell** — Viewport and layout tuned so core tabs (Games, Studio, Shop, Coins, Friends, Safety, Settings) stay reachable on narrow screens.

Safehouse (3.0) builds on this foundation with safety, privacy, and trust features—not replacing the mobile bridge.
