## Summary

Pixel Place now ships a **World Generator** in Games → Tools: describe a world, watch a live 3D sketch rebuild from your prompt, then render a real AI flythrough on cloud GPUs — no giant local model download.

## What’s new in 3.03

- **World Generator** tool in the Games tab (Tools): prompt in, world out.
- **Live sketch** — Three.js preview that rebuilds biome, props, and layout from your wording as you type.
- **Cloud render** — kick off a flythrough job on cloud GPUs (Vertex AI Veo by default; optional fal / LingBot when configured).
- **Optional reference image** — attach a still to steer the look when you want more than text.
- **Job status polling** — track progress and open the finished video when it’s ready.
- Reliability fix so text-only jobs no longer fail on an empty `imageUrl` in Firestore.
