# Quick Guide: Install Rojo Plugin in Roblox Studio

## ✅ Easiest Method (Recommended)

1. **Open Roblox Studio**
2. **Go to this link:** https://www.roblox.com/library/1317044213/Rojo
3. **Click "Get Plugin"** or "Add to Studio"
4. **Done!** The plugin will appear in Studio's toolbar

## 🔧 Alternative: Use Studio Toolbox

1. Open Roblox Studio
2. Click the **Toolbox** tab (right side panel)
3. Search for **"Rojo"**
4. Click on the Rojo plugin result
5. Click **"Add to Studio"**

## 🚀 After Installation

1. **Start Rojo server** (in your terminal):
   ```powershell
   cd "Pixel-Place"  # or navigate to your Pixel-Place project folder
   rojo serve
   ```

2. **In Roblox Studio:**
   - Look for the **Rojo button** in the toolbar (top menu)
   - Click it
   - Click **"Connect"**
   - Your files will sync!

## ❓ Troubleshooting

**Plugin button doesn't appear?**
- Restart Roblox Studio
- Check: View → Toolbars → make sure Rojo is enabled

**Connection fails?**
- Make sure `rojo serve` is running
- Check the port (default: 34872)
- Restart both Rojo and Studio

**Can't find the plugin?**
- Make sure you're logged into Roblox Studio
- Try the direct link: https://www.roblox.com/library/1317044213/Rojo
