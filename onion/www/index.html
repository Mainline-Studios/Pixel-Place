This is a private onion site for Pixel Place by Mainline Studios. It is not advertised on the public web. You reached it through Tor’s overlay network using a randomly generated v3 address.

loading.onion

What this is

A localhost-only Nginx origin published as a Tor onion service. Visitors never talk to this host’s public IP; Tor decrypts the circuit on the server and forwards HTTP to 127.0.0.1:8080.

How to open it

  • Use Tor Browser.
  • Paste the .onion address above into the URL bar.
  • Do not expect this hostname to resolve on the ordinary internet.
