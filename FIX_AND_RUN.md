# Fix Localhost & Run

## 🚀 EASIEST WAY - Double Click This File:

**`START.bat`** - This will automatically:
- Check if Node.js is installed
- Install dependencies if needed
- Start the server
- Show you the URL

## OR Manual Steps:

### 1. Open PowerShell/Command Prompt

### 2. Navigate to project:
```powershell
cd "c:\Users\Landon Boehm\Pixel-Place"
```

### 3. Install dependencies:
```powershell
npm install
```

### 4. Start server:
```powershell
npm run dev
```

### 5. Copy this URL into your browser:
```
http://localhost:3000
```

## ⚠️ If Port 3000 is Busy:

The server will automatically try a different port. Check the terminal output for the actual URL (it will say "Local: http://localhost:XXXX")

## 🆘 Still Not Working?

1. Make sure Node.js is installed: https://nodejs.org/
2. Run `npm install` first
3. Check terminal for error messages
4. Try a different port: `npm run dev -- -p 3001`
