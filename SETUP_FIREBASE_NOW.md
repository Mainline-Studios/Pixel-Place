# 🚀 Quick Firebase Setup

## What You Need to Do:

1. **Go to Firebase Console**: https://console.firebase.google.com/
2. **Sign in** and enter any verification codes when prompted
3. **Select project**: `pixel-place-823b1` (or create it if it doesn't exist)
4. **Enable Firestore**:
   - Go to "Firestore Database" in left menu
   - Click "Create Database"
   - Choose location and enable

5. **Get Service Account Key**:
   - Go to Project Settings → Service Accounts
   - Click "Generate New Private Key"
   - Download the JSON file

6. **Once you have the JSON file**, tell me and I'll configure it for you!

## Or If You Already Have the JSON:

Paste the contents here and I'll set it up, or save it as `firebase-service-account.json` in the project root.
